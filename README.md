# OA 资产评估项目流程管理系统

本仓库用于资产评估项目从创建、合同审核、报告评审、签发、文印、邮寄、开票到归档的业务管理。

## Agent 使用支持入口

**请先完整阅读 [OA 系统 Agent 使用支持说明书](docs/agent-support-manual.md)。**

说明书包含角色和权限、页面入口、状态识别、正常办理步骤、资料继承、常见报错、已知缺陷、只读诊断和升级处理规范。它是使用支持知识，不是执行审批或操作生产数据库的授权。

- 架构和数据模型：[架构](docs/architecture.md)、[数据模型](docs/db-schema.md)
