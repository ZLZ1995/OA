# 中勤评估业务OA系统桌面端验收清单

## 1. 文档目标
本文档用于定义桌面端一期交付后的验收项、预期结果与重点回归范围，确保需求、技术方案与实际产物一致。

## 2. 基础安装验收
- 可成功生成 Windows `.exe` 安装包
- 安装包可在目标 Windows 环境正常安装
- 应用安装完成后可正常启动
- 卸载后应用主体可移除
- 卸载后重新安装可再次正常启动

## 3. 启动与窗口验收
- 应用启动后显示标题“中勤评估业务OA系统”
- 主窗口默认加载正确的 OA 地址
- 登录成功后可正常进入 OA 主界面
- 刷新页面后当前登录态表现正常
- 关闭并重新打开应用后，可恢复上次窗口大小与位置
- 当上次窗口位置超出显示器范围时，应用会自动回到可见区域

## 4. 地址配置验收
- 默认前端地址为 `https://zhongqinoa01.com/`
- 默认后端地址为 `https://zhongqinoa.zeabur.app`
- 管理员可进入地址配置界面并修改地址
- 普通用户不可修改地址
- 地址修改后重启应用仍然生效
- 可通过“恢复默认地址”恢复为预设值
- 地址配置错误时，用户仍可回到默认配置，不会永久卡死

## 5. 下载验收
- 合同附件下载会弹出保存位置选择框
- Excel 导出会弹出保存位置选择框
- 培训手册下载会弹出保存位置选择框
- 设置默认下载目录后，保存对话框默认打开该目录
- 即使设置了默认下载目录，每次下载仍需用户确认保存位置
- 用户取消保存时，下载被取消且不出现异常状态

## 6. 托盘与关闭行为验收
- 应用启动后存在托盘图标
- 托盘菜单可正常显示
- 托盘菜单中的“显示主窗口”可恢复主窗口
- 托盘菜单中的“检查更新”可触发更新检查
- 托盘菜单中的“设置”可打开设置界面
- 托盘菜单中的“退出”可彻底退出应用
- 点击窗口关闭按钮时，会弹出“退出或后台运行”的确认
- 选择后台运行后，主窗口隐藏但应用仍驻留托盘
- 选择彻底退出后，应用进程关闭

## 7. 开机自启验收
- 应用首次安装后的默认状态为开机自启开启
- 用户可在设置中关闭开机自启
- 关闭后重启系统，应用不再自动启动
- 重新开启后重启系统，应用可自动启动

## 8. 自动更新验收
- 应用启动时会自动检查更新
- 无更新时应用可继续正常使用
- 存在普通更新时，会提示用户可立即更新或稍后处理
- 存在关键更新时，旧版本不能直接继续进入主业务
- 更新下载完成后可提示重启安装
- 更新失败时可提示用户稍后重试

## 9. 消息提醒验收
- 后台运行时可继续监听新通知
- 仅待办类、需要处理类消息触发桌面提醒
- 普通通知不弹桌面提醒
- 已读通知不重复弹桌面提醒
- 每条提醒均包含关闭标志和“立即处理”按钮
- 点击关闭标志后，仅关闭当前提醒，不影响应用其他功能

## 10. 立即处理验收
- 登录态有效时，点击“立即处理”可直接进入目标业务页
- 登录态失效时，点击“立即处理”会先进入登录页
- 登录成功后会自动跳回原目标业务页
- 从桌面提醒进入项目流程页时，跳转结果与 Web 工作台点击“进入项目”一致
- 项目类通知可跳转到 `/projects/{id}/flow`
- 工单类通知可跳转到 `/workorders/{id}`
- 无有效目标的通知不会错误跳转到无关页面

## 11. 外链验收
- 外部链接可在 App 内打开
- 外链页面不会替换主 OA 窗口的核心桌面能力
- 外链打开后，主窗口仍可正常返回和使用

## 12. 业务回归验收
- 登录与退出流程正常
- 项目工作台可正常进入
- “进入项目”可正常使用
- 文件上传流程正常
- 文件下载流程正常
- 消息中心与待办联动正常
- 关键业务流程页面在桌面端显示正常

## 13. 异常场景验收
- 前端地址不可达时有错误提示
- 后端地址不可达时通知与更新失败可感知
- 下载目录失效时可重新选择目录
- WebSocket 断开后应用可重连或退化为可接受状态
- 更新服务异常时不会导致应用直接崩溃

## 14. 通过标准
当以下条件全部满足时，可判定桌面端一期达到可交付状态：
- 五大核心能力可用：
  - 启动与安装
  - 托盘与后台运行
  - 下载管理
  - 更新检查
  - 待办提醒与立即处理
- 地址配置、权限限制、登录恢复逻辑均符合约定
- 核心业务操作未因桌面封装出现阻断性回归
